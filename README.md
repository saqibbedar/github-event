# Event Archive

This repository is an archive and study companion for the GitHub Mastery Bootcamp - Day 2 session organized by [Microsoft Learn Student Ambassadors QAU](https://www.linkedin.com/company/microsoft-learn-student-ambassadors-qau).

The session was delivered by MSLA QAU, and it focused on the practical essentials of Git and GitHub for developers, from local workflow basics to project deployment using GitHub Pages.

> Website: https://saqibbedar.github.io/github-event/

## Event Details

- Topic: GitHub: Learn what matters
- Speaker: Saqib Bedar
- Date: 21st Sep, 2024
- Time: 09:00 PM
- Venue: MS Teams
- Organizer: Microsoft Learn Student Ambassadors QAU

## Why this repo exists

This project collects the most useful takeaways, examples, notes, and commands from the session in a single place for future reference. It is intended as a practical Git/GitHub learning shortcut, especially for developers starting out or revisiting the fundamentals.

## Topics covered

1. Introduction
2. Git vs. GitHub: understanding the difference
3. GitHub vs. social media platform
4. Git repositories: remote and local
5. Working locally: managing projects with Git
6. Essential Git commands
7. Working with Git branches
8. Deploying with GitHub Pages
9. Questions and discussion
